# Frontend reservado para S1 y S4

Sprint 0 solo fija carpetas y dependencias. No existe todavía una aplicación Vite,
pantallas, servidor web ni comando de build. Los tipos de la API se generarán desde
`../docs/planning/Contrato_API_demo.yaml` al comenzar la integración.

`app` contendrá composición y navegación; `components`, piezas compartidas;
`features`, recorridos por función; `lib`, cliente HTTP, fechas y tipos generados.
Las intervenciones se abrirán en el contexto de estudiantes o alertas.
